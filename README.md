# 글로컬 크래시 (GLOCAL CRASH)

충주 캠퍼스를 OpenStreetMap 실제 지도와 실제 지형(고도 자료) 그대로 세워 놓고 부수는 웹 3D 게임.
만든이: 컴퓨터공학과 김태오

- 도구 10종: 쇠파이프 · 총 · 대포 · 폭탄 · 운석 · 핵폭탄 · 지진 · 용역 호출 · 복구 · 짓기(블록·벽·집·탑)
- 이벤트: 시설팀(방패) · 공군 대민지원 · 수강생 시위/폭동 · 교수님 종강 · 전투기 · 산타 썰매
- 장학금 · 콤보 등급 · 피해 단계 · 학기 성적표
- 걸어 다니는 학생, 유리창 너머 학과별 수업 장면
- 같이 하기(초대 코드): 같이 부수기 / 부수기 vs 복구
- 결과 카드 공유 (세로 이미지)
- 나 vs 막는 세력: 교직원 · 시설팀 · 군 방어부대(방벽·대공포) · 방공 전투기 · **총장 보스**
- 전투기 공습 · 미션 16종(장학금·뽑기권 보상)
- 유닛 뽑기(일반·희귀·에픽·전설): 전차 · 미사일 차량 · 드론 · 불도저 · 공습 · 거대 로봇
- 사람 분류(남학생·여학생·교수·학생회·교직원…) · 건물 피해 분류 · 현황 창 · 설정(세기·화질·FPS)
- 10판: 보관함 10칸·버리기 · 충주시장 이동석/충주맨/총장 협상 · **최강 네임드 김태오** · 모시래 축제/모람제/벚꽃축제/체육대회 · 시험 기간 · 환경미화원(송풍기) · 오토바이 · 건물 점령/내 세력 · 기부 신축/리모델링 · 팔다리 움직이는 다양한 사람 · 말소리/웅성거림/시위 구호 · 닉네임·학과 랭킹 · 자동 화질
- 11판: 사계절 · 카페 레스티오 · 계정/누적 기록 · 세력 다툼(질서유지대·용역 vs 시설팀) · 보관함 3탭(아이템·장비 2칸·내 세력 생산) · 내 건물 세우기 · 시점 판(회전·기울이기·눈높이)
- 크리스마스 버전: `christmas.html`
- 온라인 랭킹(선택): `rank-config.js`에 Supabase 주소·공개 키 (개발명세서 70절)

## 실행
- `index.html`(기본) 또는 `christmas.html`(크리스마스)을 브라우저로 열기. 같은 폴더에 `campus-data.js` 필요
- 또는 이 폴더에서 `python -m http.server` 후 `http://localhost:8000`

## 다시 만들기
- 지도 데이터: `node tools/build-campus.mjs` (원본 `data/*.osm`)
- 크리스마스 판: `index.html`을 고친 뒤 `node tools/build-xmas.mjs`
- 공개 배포: `node tools/deploy.mjs "바뀐 내용"` → `../glocal-crash-site`에 복사·커밋 → 그 폴더에서 `git push` (GitHub Pages가 1분쯤 뒤 반영)
