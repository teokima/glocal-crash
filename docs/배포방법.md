# 글로컬 크래시 · 배포 방법

## 지금 공개 주소
- 기본: https://teokima.github.io/glocal-crash/
- 크리스마스: https://teokima.github.io/glocal-crash/christmas.html
- 이 주소를 카카오톡·인스타·에브리타임에 그대로 보내면 됩니다. 미리보기 그림(og.png)이 같이 뜹니다.
- 휴대폰에서는 브라우저 메뉴 → **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생기고 전체 화면으로 열립니다.

## 고친 뒤 다시 올리기 (명령 하나)
바탕화면의 `glocal-crash` 폴더에서:

```
node tools/deploy.mjs "바뀐 내용 한 줄"
```

이 명령이 하는 일:
1. 크리스마스 판(christmas.html)을 다시 만듦
2. 게임 파일만 `../glocal-crash-site`로 복사 (index.html, christmas.html, campus-data.js, rank-config.js, README.md, og.png, 아이콘, manifest, docs)
3. 커밋 → GitHub(teokima/glocal-crash)로 푸시
4. 1~2분 뒤 GitHub Pages에 반영 (브라우저에서 Ctrl+F5)

커밋만 하고 올리지 않으려면 끝에 `--no-push`를 붙입니다.

## 처음 한 번만 필요한 것
- Node.js, Git 설치
- GitHub 로그인: `gh auth login` (지금 컴퓨터는 이미 되어 있음 · 확인은 `gh auth status`)

## 다른 곳에 올리고 싶다면
- **Netlify / Vercel / Cloudflare Pages**: `glocal-crash-site` 폴더를 그대로 끌어다 놓으면 됩니다(빌드 과정 없음, 정적 파일).
- **나만의 주소(도메인)**: 도메인을 산 뒤 GitHub 저장소 Settings → Pages → Custom domain에 입력하고, 도메인 업체에서 CNAME을 `teokima.github.io`로 설정.

## 관리자 모드 (방문자·플레이 시간)
- 주소 뒤에 `?admin`: https://teokima.github.io/glocal-crash/?admin
- 모든 사람의 기록을 보려면 아래 Supabase 연결이 필요해요. 연결 뒤 SQL Editor에서 개발명세서 105절의 SQL을 한 번 실행하세요(관리자 화면에도 [SQL 복사] 단추가 있어요).

## 온라인 랭킹·회원가입 켜기 (선택)
1. supabase.com에서 무료 프로젝트를 직접 만듭니다.
2. `rank-config.js`에 프로젝트 URL과 **anon 키**만 넣습니다. (service_role 키는 절대 넣지 않음)
3. 위 배포 명령으로 다시 올립니다.
