## 1. 왜 만드는가

캠퍼스 건물을 부수는 웹 게임이 학생들 사이에서 인기를 끌고 있다. 같은 갈래의 게임을 우리 손으로 만들되, 그냥 따라 만드는 데서 그치지 않고 **"살아 있는 캠퍼스"를 부수는 손맛**에 집중한다.

기존 캠퍼스 파괴 게임에서 아쉬웠던 점과 우리 게임이 채우려는 점은 아래와 같다.

| 아쉬운 점 | 우리 게임에서 바꾸는 점 |
|---|---|
| 캠퍼스 배치가 실제와 다르면 몰입이 깨진다 | 건물·도로·주차장·운동장을 **OpenStreetMap 실제 지도 데이터**로 세운다. 건물 윤곽과 기울어진 방향까지 실제와 같다 |
| 캠퍼스가 멈춰 있는 모형 같다 | 차와 버스가 도로를 달리고, 버스는 정류장에 서고, 길이 막히면 경적을 울린다 |
| 노천극장이 그냥 건물 하나다 | 노천극장을 **실제 공연이 열리는 공연장**으로 만든다. 실제 무대 지붕 위치에 맞춰 무대·전광판·조명·밴드·관객 260명·음악을 둔다 |
| 무기가 판타지 위주다 | 쇠파이프·총·대포처럼 **손에 잡히는 무기**를 넣는다 |
| 캠퍼스가 플레이어 혼자 노는 무대다 | 캠퍼스 사람들에게도 **권한**을 준다. 시설팀은 방패로 막고 고치고, 공군 장병은 복구를 돕고, 수강생은 시위·폭동을 일으키고, 교수님은 종강으로 캠퍼스를 되살린다 |
| 부순 뒤 반응이 없다 | 공연이 중단되고 관객이 대피하며, 잔해가 도로를 막아 교통이 멈춘다 |

## 2. 목표

### 2.1 꼭 이룰 목표 (2판까지 완료)
1. OpenStreetMap 데이터로 캠퍼스 38동과 주변 원룸촌 135동을 **실제 윤곽·위치·방향** 그대로 블록으로 세우고, 블록 단위로 부서지게 한다. (1판은 가상 배치였고 2판에서 바꿈)
2. 땅과 이어진 부분이 끊기면 위쪽이 통째로 무너지게 한다 (구조 붕괴).
3. 무기 6종: **쇠파이프, 총, 대포**, 폭탄, 운석, 지진.
4. 노천극장 공연: 실제 노천극장 윤곽과 무대 지붕 위치에 무대, 전광판, 무빙 조명, 공연자 4명, 관객 260명, 직접 합성한 음악.
5. 교통: 실제 도로 연결망(충원대로·중원대로·캠퍼스 안 길)을 따라 승용차 44대·버스 6대가 운행. 실제 버스정류장 9곳 정차, 실제 주차장 30곳에 주차 차, 앞차·잔해 감지, 전복.
6. 점수·콤보·파괴율, 되돌리기(Ctrl+Z), 전부 복구, 낮·밤, 사진 저장.
7. 휴대폰 터치 조작.

## 3. 범위와 지켜야 할 선

- **학교 로고·교표·공식 상징은 쓰지 않는다.** 건물 이름만 실제를 빌린다.
- 건물 위치·모양·도로는 OpenStreetMap 데이터(ODbL)를 쓰고, **출처를 첫 화면과 게임 화면에 표시**한다. 층수와 색은 추정임을 밝힌다.
- 지도 데이터 파생물(`campus-data.js`)은 ODbL 조건(출처 표시, 같은 조건 공개)을 지킨다.
- 다른 게임의 화면, 그림, 문구, 이름을 그대로 가져오지 않는다. 같은 갈래(캠퍼스 파괴)의 게임을 **우리 디자인으로** 새로 만든다.
- 사람(관객·공연자)은 공격 대상이 아니다. 폭발이나 총소리가 나면 **놀라서 대피**하고, 공연이 다시 열리면 돌아온다. 차는 빈 차로 보고 뒤집히거나 불탄다.
- 비공식 팬 게임임을 첫 화면에 적는다.

## 4. 기술 선택

| 영역 | 선택 | 고른 까닭 |
|---|---|---|
| 3D 그리기 | three.js 0.160 (CDN) | 웹 3D 표준, 설치 없이 import map으로 불러옴 |
| 카메라 조작 | MapControls | 지도처럼 끌어서 이동, 휴대폰 두 손가락 회전·확대 기본 제공 |
| 이름표 | CSS2DRenderer | 한글 글꼴이 깨끗하게 나옴 |
| 물리 | **직접 작성** | 블록·잔해 수천 개를 가볍게 돌리려면 범용 물리 엔진보다 단순한 전용 계산이 빠르다 |
| 소리 | Web Audio API 합성 | 소리 파일 0개, 저작권 걱정 없음, 용량 0 |
| 지도 | OpenStreetMap + 직접 만든 변환 도구(Node) | 공개 지도라 누구나 쓸 수 있고, 지도가 바뀌면 명령 한 줄로 다시 만듦 |
| 파일 구성 | HTML 1개 + 데이터 JS 1개 | 더블클릭이나 정적 호스팅만으로 실행 |

| 후원 계좌가 공개 페이지에 노출 | 확정 | 작음 | 만든이 본인 요청. 계좌번호는 `#donate` 한곳에만 있어 바꾸기 쉬움 |
| 학교 측 상표 문제 | 낮음 | 큼 | 로고·교표 미사용, 비공식 표기, 건물 이름은 지도 데이터에서 오므로 변환 도구에서 한 번에 바꿀 수 있음 |

## 7. 완료 기준

- 첫 화면에서 "부수러 가기"를 누르면 오류 없이 캠퍼스가 뜬다. → **확인함** (헤드리스 크롬에서 콘솔 오류 0건)
- 위에서 본 건물·도로 배치가 OpenStreetMap 지도와 같다. → **확인함** (위에서 보기 화면 비교)
- 6개 무기가 모두 동작하고, 되돌리기와 전부 복구가 점수·블록·잔해·나무·차를 원래대로 돌린다. → **확인함**
- 노천극장 근처를 공격하면 공연이 멈추고 관객이 대피하며, 12초 뒤 무대가 멀쩡하면 공연이 다시 열린다. 무대 바닥이 절반 넘게 부서지면 공연이 취소된다. → **확인함**
- 실제 그래픽 카드가 있는 PC에서 60fps 근처, 보통 휴대폰에서 30fps 이상. → 2주차에 실제 기기로 측정 예정 (헤드리스 소프트웨어 렌더링 수치는 기준으로 쓰지 않음)
