# 글로컬 크래시 · 스토리 대본 〈버그의 학기〉

> 게임 안 대화를 그대로 옮긴 대본입니다. 고치고 싶은 대사는 `index.html`의 `STORY`(12-42절)에서 바꾸면 됩니다.

## 줄거리
이 캠퍼스는 컴퓨터공학과 김태오가 만든 '아무 일도 일어나지 않는 완벽한 캠퍼스 시뮬레이션'입니다. 플레이어는 거기서 튀어나온 **버그**라서, 손만 대면 블록이 무너집니다. 마스코트 **쿠**가 길잡이가 되어, 한 학기 16주 안에 캠퍼스를 뒤흔들어 '진짜 캠퍼스'로 가는 문을 열려고 합니다. 조남주 학생주임, 교수 세력의 학장, 충주시장 이동석, 총장이 차례로 막아서고, 충주맨은 브이로그를 찍으러 오며, 마지막 16주차엔 만든이 김태오가 개발자 권한으로 직접 나섭니다.

## 엔딩 3가지
- **진짜 캠퍼스**: 김태오를 쓰러뜨림
- **학생들의 캠퍼스**: 김태오는 못 이겼지만 지배율 50%
- **다음 학기에**: 둘 다 못 함
